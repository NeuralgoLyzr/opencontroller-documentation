---
title: "Spend"
description: "The Spend page totals what your organization spends on AI: the clouds' bills, the licences people hold, and the model calls OpenController sees."
---

Spend is money. It adds up the bills of the connected clouds and AI providers, the licences people hold at the prices you set, and the model calls OpenController traces, and shows where each goes. Who holds which licence is the [People](/discover/people) page.

**Who can do this:** `spend:read` to see the page. `spend:refresh` for **Refresh**. `spend:prices` to set licence prices. `spend:people` for the per-person panels.

## Time ranges

The period selector offers **This month**, **Last month**, **30 days** and **7 days**. Bills arrive by the day, so a week is the shortest period. Every number that shows a change compares the period with the one before it: for a month, the previous month to the same day.

## The five numbers

| Number | What it is |
|---|---|
| **Total AI spend** | Bills plus licences over the period, against the period before. |
| **Bills** | What the clouds and AI providers billed, plus what is estimated. The line beneath gives the estimated part and where the month is heading at its pace so far. A sparkline shows the trend. |
| **Licences** | The licences held, at their monthly price, for the length of the period. Beneath: the monthly total, the seats, and how many licences have no price set. |
| **Idle licences** | What the seats unused for 30 days cost a month. Reads "Needs usage reports to tell" when the licence source cannot read usage. |
| **Traced model calls** or **Through the LLM gateway** | Model calls OpenController itself sees: through observability traces when that module is on, otherwise through the LLM gateway. These may also be in a cloud's bill, so they are not added to the total. |

## Panels

- **Bills, day by day**: billed and estimated spend per day, stacked by provider. Bills settle a day or two late, so the latest days run low.
- **Unusual days**: days a service cost at least three times its daily average over the week before, and $10 more. The panel is only shown when there is something in it.
- **Where the bills go**: the bills grouped by **Services**, **Providers**, **Accounts** or **Resources**, with **Billed** and **Estimated** columns.
- **Licences**: each licence with **Seats**, its price **Each** (editable with `spend:prices`) and the seats **Idle**. The footer links to People.
- **Top agents and models**: what the bills name, joined to the AI inventory, with each one's registry standing. The console notes that Azure and Databricks bills do not name agents yet.
- **Claude API**: shown when there is Anthropic spend. Which models the bill goes to, and what prompt caching and batching cost and saved. Savings are estimates from list price ratios.
- **Top spenders** and **Spend by department**: each person's licences, usage put down to them (such as Claude Code) and, with observability on, the model calls traced as theirs. Both need `spend:people`.
- **Traced**: with observability on, the model calls seen, split by **Agents**, **People**, **Teams**, **Providers** or **Models**.
- **Sources**: every source read, through which connection, its state and when it was last read.

## What feeds it

Spend is read through the integrations connected under Integrations. Each source is read after a discovery scan of its connection, at most every six hours (once a day where reading costs money), and on **Refresh**.

| Source | What it reads |
|---|---|
| Microsoft 365 licences | The licences people hold, and their last use where the permission allows |
| Azure AI costs | The Azure bill for AI services |
| AWS Bedrock and AgentCore bill | The AWS bill for Bedrock and AgentCore |
| AgentCore runtime hours | AgentCore runtime usage |
| Google Cloud AI costs | The Google Cloud bill for AI services |
| Databricks AI usage | Databricks AI usage |
| Claude API bill | Anthropic's cost report, by model, token type and tier |
| Claude Code by person | Claude Code usage attributed to each person |

A source's state is **Read**, **Needs a permission** (the missing permission is named), **Not set up** or **Failed**. A source that fails keeps what it read before.

<Note>
Model calls through the LLM gateway or seen in traces are shown apart from the bills. A call through Bedrock or Azure is already in that cloud's bill.
</Note>

## API

| Method | Path | Returns |
|---|---|---|
| `GET` | `/v1/spend` | The summary over a window: bills, estimates, seats, sources |
| `GET` | `/v1/spend/breakdown` | Spend by provider, service, account, resource, SKU, kind, source, asset, meter or tier; seats by person, department or SKU |
| `GET` | `/v1/spend/daily` | Spend day by day |
| `GET` | `/v1/spend/assets` | Spend by agent or model |
| `GET` | `/v1/spend/anomalies` | Unusual days |
| `POST` | `/v1/spend/refresh` | Read every source now |
| `GET` / `PUT` | `/v1/spend/prices` | Licence prices by SKU |
