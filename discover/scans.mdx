Scans run on their own, one schedule per connection, and you can start one at any time with **Run scan** (on **Overview**, or under **Discovery scans** on **Integrations**).

## What a scan does

- **Run scan** reads every enabled integration of each connected cloud. A cloud already scanning is left to finish.
- With no AWS account connected, a scan reads the service's own AWS account.
- A source is one resource family in one account and region. A source that fails keeps what the last good scan found, so nothing disappears from the inventory because of a missing permission.
- To scan only the clouds behind one asset, select **Rescan** on its page. See [Asset details](/discover/asset-details).
- Scan records are kept for 30 days.

## Set the scan schedule

Go to **Settings** > **Scan schedule**, or select **Change** in the schedule line under **Discovery scans**. Each connection is scanned one interval after its last scan, whoever started it.

- **Scan every** sets the interval, from 5 minutes to 1 day, or **Custom…** (1 to 10,080 minutes).
- **Off: only when started** scans the connection only when someone selects **Run scan**.
- **Default** uses the server's interval. Changes are recorded in the audit log.
