The AI Inventory is the catalog of what discovery found: every agent, and every model, MCP server, tool, identity and other asset an agent is built from or can reach. It is shown two ways: as a map of the whole estate, and as a filtered list. This page covers the list and the asset detail page; the map is on [Map and graph](/discover/map).

**Who can do this:** `assets:read` to read the inventory. `graph:read` for the map view. `scans:run` for **Rescan**.

## The strip

Five numbers head the page: **Assets** (with the number of kinds), **Accounts** (across how many clouds), **Agents** (with how many are registered and shadow), **What they use** (every non-agent asset, naming the three largest kinds), and **Registered** (the share of governed assets registered). Without the register module the last is **Kinds**.

## Agents and All assets

The list opens on **Agents**. **All assets** shows every kind. Filters live in the URL, so a filtered view can be linked and reloaded; a link with filters opens on the list.

## Filters

| Filter | Values |
|---|---|
| **Search** | Name or ARN. Commits on Enter or when you leave the field. |
| **Kind** | The kinds present in the inventory. |
| **Cloud** | AWS, Microsoft, Databricks, Google Cloud, Anthropic, Snowflake, External. |
| **Source** | The product within a cloud, for example Copilot Studio, Azure AI Foundry, Bedrock AgentCore, Agent Bricks, Cortex Agents, Remote MCP servers. Picking a cloud narrows the list of sources. |

**More filters** folds the rest away and shows how many of them are set:

| Filter | Values |
|---|---|
| **Exposure** | Any, Public, Organization, Private |
| **Authentication** | Any, Required, None |
| **Account** | An account, subscription, tenant or workspace id |
| **Region** | A region |
| **Include removed** | Also list assets no source reports any more |

## Columns

| Column | What it shows |
|---|---|
| **Name** | The asset's name, or its key when it has none |
| **Kind** | The kind badge |
| **Source** | The cloud and product, and through which cloud an external asset was found |
| **Type** | What the asset is within its product, in words. The raw platform id is the tooltip |
| **Account** | The account id |
| **Region** | The region, or "global" |
| **Status** | The platform's own status word, or "Removed" |
| **Registry** | Where it stands in the registry (only with the register module) |
| **Last synced** | When a scan last reported it |

The **Registry** column shows one of **Registered**, **Awaiting approval**, **Shadow** (of a kind the policy governs, nobody has registered it) or **Not governed** (the policy does not name its kind). Pages hold 50 rows. A removed asset is shown faint.

Clicking a row opens the asset in a side panel. Opening it in a new tab, or **Open full page** in the panel, opens `/inventory/<id>`.

## Asset kinds

Agent, MCP server, Tool, Gateway, Skill, Model, Endpoint, Memory, Knowledge base, Browser, Code interpreter, Credential provider, Identity, Policy engine, Guardrail, Registry, Registry record, Artifact.

## The asset page

The header names the asset, its source and where it resides (project, environment or workspace), its kind, its type, its status, when it was created and when it was last synced. Beneath are **Rescan**, which rescans the clouds that reported the asset, and the **Actions** menu: **Open full page**, **Open in Shadow AI map**, **View on the map** and **Copy resource ID**.

## API

| Method | Path | Returns |
|---|---|---|
| `GET` | `/v1/assets` | Discovered assets, filtered and paged |
| `GET` | `/v1/assets/{asset_id}` | One asset |
| `GET` | `/v1/assets/{asset_id}/neighbors` | What it uses, and what uses it |
| `GET` | `/v1/assets/summary` | Live assets by kind |
| `GET` | `/v1/assets/places` | Where the assets are |
| `GET` | `/v1/assets/{asset_id}/ownership` | Who answers for it |
