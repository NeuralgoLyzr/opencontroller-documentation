## What each integration unlocks

Each integration connects one account, tenant or workspace with a read credential.

| Integration | Signs in as | What it finds |
|---|---|---|
| **AWS** | A read-only IAM role, with an external ID | Bedrock AgentCore and Bedrock agents, across enabled regions |
| **Microsoft** | An Entra app registration | Copilot Studio, Agent Builder, Foundry and Agent 365 agents, and who they are shared with |
| **Databricks** | A service principal | Agents, models, MCP servers and skills; AI spend from billing |
| **Google Cloud** | A read-only service account | Agent Runtime, Managed Agents, Agent Registry and CX Agent Studio |
| **Anthropic** | An Admin API key, used only to read | Claude models and API keys in use; cost and Claude Code use by person |
| **Snowflake** | A service user | Cortex Agents and their tools, MCP servers and Cortex Search |

Secrets you enter go to the organization's secrets manager. They are never shown again, returned by the API or logged.

## What to know

- **Verify checks each permission separately.** A missing one fails only its own part; everything else is still read, and what the last good scan found is kept.
- **Control is optional.** It is a second credential, kept apart, that changes are made as (blocking or sharing an agent). Without it, OpenController changes nothing.
- **Guardrail credentials** for a cloud's own guardrails (AWS Bedrock Guardrails, Azure AI Content Safety, Google Model Armor) are kept on that cloud's integration. See [Cloud guardrail providers](/secure/guardrails/cloud-providers).
- **Scans** run every 5 minutes per provider. Until an AWS account is connected, they read the service's own AWS account. See [Scans and the scan schedule](/discover/scans).
- **Removing an integration** deletes its stored secrets. Discovered assets stay until later scans retire them, and the role or app in the provider stays for you to remove.

## Who can use it

| Role | What they can do |
|---|---|
| **Viewer** | Read the integrations and the scans. |
| **Operator** | Also **Verify** and **Run scan**. |
| **Admin** | Also connect, change, disable and remove integrations, update secrets, and set control and guardrail credentials. |
| **Owner** | Everything an Admin can do. |
