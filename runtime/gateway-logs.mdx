**Logs** lists the calls made through the LLM gateway, newest first. It is the place to see what an agent actually
called, whether the call succeeded, and what it cost. The prompts and answers themselves stay in the gateway; this
page lists the calls and lets operators search their content.

Who can do this: `modules:read` reads the logs. Searching prompts and answers needs the Operator role
(`modules:use`), since the search reads what was asked and answered.

## Filters

| Filter | Options |
|---|---|
| Window | **Last hour**, **Last 24 hours** (the default), **Last 7 days**, **Last 30 days**. |
| Status | **Any status**, **Succeeded**, **Failed**, **Running**. |
| **Search prompts and answers** | Free text matched against the content of calls. Shown only when the connected gateway can search content; Rekori can. |

Changing a filter returns to the first page. The list is paged.

## Columns

| Column | Meaning |
|---|---|
| **When** | How long ago the call was made; the exact time shows on hover. |
| **Model** | The provider and model called, as `provider/model`. When a routing rule sent the call, a second line says **via** which rule. |
| **Status** | **Succeeded**, **Failed** or **Running**. On a failed call, the gateway's error shows on hover. |
| **Caller** | The virtual key the call was made with, and its team or customer. |
| **Tokens** | Total tokens used by the call. |
| **Latency** | How long the call took, in milliseconds. |
| **Cost** | What the call cost, in US dollars, as the gateway prices it. |

A cell shows a dash when the gateway recorded no value for it.

## What a log line holds

OpenController reads each call from the gateway as: its id, when it was made, the provider and model, its status,
latency, total tokens, cost, the virtual key, team and customer it is attributed to, the routing rule that sent it,
and the error message if it failed.

What it does not hold:

- **The prompt and the answer.** They are kept by the gateway, not by OpenController. The content search sends your
  words to the gateway and shows the calls that match; the text itself is not shown on this page.
- **The guardrail outcome.** What the gateway's content rules blocked or redacted is a separate record, read on the
  [Guardrail violations](/runtime/guardrail-violations) page.

## Empty states

- **No calls**, "Nothing went through the gateway in the last 24 hours": nothing in the window.
- **No calls**, "Nothing matches these filters": a status or search narrowed the list to nothing.

## Retention

The gateway keeps the logs, so retention is set in the gateway, not in OpenController. In Rekori, the client
setting `log_retention_days` says how many days log entries are kept (its documentation gives 365 as the default),
and `disable_content_logging` strips message content from the logs while keeping the metadata. With content logging
off, the content search has nothing to match.

## API

- `GET /v1/llm-gateway/calls`: the calls, with `since`, `until`, `status`, `search`, `limit` and `offset`.
- `GET /v1/llm-gateway/usage`: the counts over a window: calls, success rate, average latency, tokens and cost.
