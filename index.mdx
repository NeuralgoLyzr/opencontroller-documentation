    </Tab>
    <Tab title="Control">
      <Diagram name="credentials" alt="A read credential for discovery, a separate control credential for changes" />
      With a control credential, granted per platform, you share an agent, remove someone's access, end organization-wide sharing, block it or delete it, on the platform it runs on. Every change is audited. [Access and sharing](/discover/asset-details#access-and-sharing).
    </Tab>
    <Tab title="Run">
      <Diagram name="gateway" alt="A call enters the gateway with a virtual key, passes the content rules, reaches a provider and returns checked" />
      Applications call the LLM gateway instead of providers. Each gets a virtual key with a budget and rate limits, every call is logged, and guardrails block or redact personal data, secrets, prompt injection and off-topic use. [LLM gateway](/secure/gateway-overview) and [Guardrails](/secure/guardrails/list).
    </Tab>

    </Tab>
    <Tab title="Evaluate">

    </Tab>

You work in **the console**, the OpenController web app. Each organization has its own workspace, at its own address.

## Who it is for

| You are | You use OpenController to |
|---|---|
| A security or platform admin | Connect clouds, find all AI in use, set policies, guardrails, single sign-on and roles. |
| An AI or platform engineer | Put agents behind the LLM gateway, give them keys and budgets, try guardrails, send traces. |
| A reviewer or auditor | Read the inventory, findings, approvals and the audit log. |
| A developer | Call the same features through the API. |

What you can see and change depends on your role: **Viewer**, **Operator**, **Admin** or **Owner**. See [Roles and permissions](/get-started/roles).
