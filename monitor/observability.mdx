<Note>Needs the **Observability** module and a connected trace store. See [Turn on modules](/administer/modules).</Note>

A **project** is where traces are kept and read, usually one per agent, app or environment. A **trace** is one run of an agent, a **span** one step of it (a model call, a tool call, a retrieval, or the app's own code), and a **session** several runs that share a session id.

An OpenTelemetry Collector writes the spans to the trace store, and OpenController only reads them there. It keeps no copy and does not change the store. If the page says **No trace store connected**, an Admin selects **Connect the trace store** and sets it in **Settings** > **Observability**.

- **Unassigned** holds the traces sent to no project: the LLM gateway's own, or what a collector forwards. It has no Setup or Settings.
- A removed project still shows, as `<id> (removed)`, while its traces remain.

<Tip>Press **⌘P** (**Ctrl+P**) anywhere in Observability to switch project.</Tip>

## Make a project

Select **New project**. The **Name** takes letters, digits, spaces, dots, dashes or underscores, up to 64 characters. Two optional fields matter:

- **Agent**: the inventory agent the project stands for. Its traces then count for that agent, in cost and on the agent's page.
- **Team**: its members read the project's traces, even with no role in the organization.

The project opens on its **Setup** page. See [Send traces to a project](/monitor/send-traces).

**Input** and **Output**, what was asked and answered, show only to Operators and above.

## Change or remove a project

Open the project and select **Settings**. Unassigned and removed projects have no settings.

- Changing the **Agent** applies to traces sent from then on. Traces already sent keep the agent they came with.
- After **Remove**, nothing can send to the project. Its traces stay in the store, listed with the projects as removed.

## Who can use it

- **Viewer** reads everything except what was asked and answered. A member of a project's team reads that project too.
- **Operator** also reads what was asked and answered, and can send traces with an API key.
- **Admin** and **Owner** also make, change and remove projects, open Setup, create API keys, and set the trace store under **Connection**.
