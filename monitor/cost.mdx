The **Cost** page turns the traces into a bill. It sums what every model call cost across all projects, or within one project, for a window of time, and breaks the total down by whoever or whatever you want to charge it to. Where the posture shows risk, Cost shows spend, and both use the same projects and agents.

## Where prices come from

A price travels with the span. OpenController reads the GenAI usage cost attribute, or the OpenInference total cost, from each model call and adds them up; it does not keep a price list of its own for traced calls.

- A call made through the [LLM gateway](/runtime/llm-gateway) is priced by the gateway, which writes the cost onto its span. The gateway's span is the one priced, so a call is never counted twice when both the SDK and the gateway traced it.
- A call made straight to a provider arrives unpriced unless the SDK that traced it set a cost attribute.
- A model call is counted once per trace, at the deepest span that carries usage.

When some calls in the window carry no price the page says so: **N model calls came with no price**, with a link to set a price for a model in the gateway's pricing overrides (`/llm-gateway/pricing-overrides` in the console). The totals on the page cover only the priced calls.

## Time ranges

The window is **Last hour**, **Last 24 hours**, **Last 7 days** or **Last 30 days**. Each figure is compared with the window before it. **Spend over time** buckets the window by minute for the last hour, by hour for a day or a week, and by day for 30 days.

## What is on the page

| Metric | What it is |
|---|---|
| **Cost** | The window's priced spend, against the window before |
| **Monthly pace** | At this window's rate, what 30 days would cost |
| **Per run** | The average per model call, and per thousand tokens |
| **Failed calls' spend** | What was spent on calls that errored |
| **Model calls**, **Input tokens**, **Cached input**, **Output tokens** | The volume behind the spend |

**Spend over time** charts the window. **Split by** chooses **Total**, **Projects**, **Models**, **Providers** or **Agents**; the chart shows the top five and folds the rest into **Everything else**. **Costliest runs** lists the traces that cost the most and opens each.

**Breakdown** is a table grouped by one of:

| Group | Notes |
|---|---|
| **Projects** | Only when looking across all projects |
| **Models** | The model the response named |
| **Providers** | The model's provider |
| **Agents** | The inventory agent each project stands for; traces whose project has none show as **No agent named** |
| **Tools & MCP** | Tool and MCP server calls |
| **Teams** | The LLM gateway's team on the key used; also the project's team |
| **Users** | The id of the user the span carries |
| **Customers** | The gateway's customer, or a customer name attribute; **No customer** otherwise |
| **Gateway keys** | The gateway virtual key; **Not through the gateway** for direct calls |
| **Services** | The `OTEL_SERVICE_NAME` of the sender |

To charge cost to an agent, give each project its **Agent** in the project's settings; see [Observability](/monitor/observability). To charge it to a team or a customer, route the agent through the gateway with a virtual key owned by that [team or customer](/runtime/teams-and-customers).
