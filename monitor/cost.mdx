<Note>Needs the **Observability** module and a connected trace store. See [Modules](/administer/modules).</Note>

Cost comes from the traces: the cost recorded on each model call's span. It is on **Observability** > **Cost** for every project, and on a project's **Cost** for that project alone.

**Monthly pace** is what 30 days would cost at this window's rate. It is not a forecast of the calendar month.

This is not the [Spend](/discover/people-and-spend) page, which reads what clouds and AI providers bill. A call through Bedrock or Azure is in both.

## Calls with no price

When some model calls came with no cost, a yellow notice under the figures names each model. Their tokens count, but their spend is missing from the figures.

Calls through the LLM gateway (Rekori) are priced by the gateway. To price a model it does not know, select **set a price for a model** in the notice. {/* TODO verify: the link opens the LLM gateway's pricing overrides page (/llm-gateway/pricing-overrides) for every gateway kind. */}

## Spend over time and breakdown

**Split by** colours the five that spent the most, and puts the rest in **Everything else**. **Spend over time** shows only when the trace store can return series. {/* TODO verify: which trace store kinds support series (ClickHouse does). */}

In **Breakdown**, a row with no name, such as **Not through the gateway** under **Gateway keys**, holds the calls that named none.

## Who can use it

- Every role, from **Viewer** up, reads Cost. A member of a project's team reads that project's cost.
- Pricing a model in the LLM gateway needs the gateway's own permissions.
