## Open Ctrl

Select **Ask Ctrl** in the sidebar, or press **⌘J** (**Ctrl+J** on Windows and Linux) from any page. Ctrl stays open on the right as you move between pages.

## Ask a question

Type in the box at the bottom and press **Enter**. With an empty conversation, Ctrl suggests questions that fit the page you are on. For example:

- "Summarize my findings"
- "Which shadow agents are the riskiest?"
- "Why did the last scan fail?"
- In **Observability**: "Why did this run fail?" or "Where did the cost go?"

## Run what Ctrl proposes

Ctrl can propose a **scan** or a **verification** of an integration. It shows as a card with **Dismiss** and **Run**, and nothing happens until you select **Run** (**Operator** role or above).

## Good to know

- **It answers from what you may see.** A **Viewer** gets answers without the prompts and answers inside traces; an **Operator** and above get them too.
- **Conversations stay in this browser tab.** Select **New conversation** to start again.
- **"The assistant is off."** means no model key is set. An **Admin** adds the Anthropic API key in **Settings** > **Secrets**.
